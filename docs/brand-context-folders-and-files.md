# Brand context folders and files

SitecoreAI organizes brand context into five folders. Each folder focuses on a different type of brand information and contains a standard set of generated files, described in the following sections.

## Audiences

The **Audiences** folder describes who the brand serves, what those audiences need, and how they make decisions.

| File | What it covers |
| --- | --- |
| **Audience Strategy** | Key audience segments, their needs, priorities, and segmentation rationale. |
| **Buyer Journey Map** | Audience needs, questions, objections, channels, and content needs across the customer journey. |
| **Industry Verticals** | Industries, sectors, markets, or other relevant contexts the brand serves. |
| **Persona Profiles** | Detailed audience profiles, including goals, pain points, decision criteria, preferred channels, and messages. |

AI can use this information to adapt content and recommendations to particular audiences and stages of the customer journey.

## Messaging

The **Messaging** folder describes how the brand presents its value, differentiation, and core story.

| File | What it covers |
| --- | --- |
| **Competitive Positioning** | Relevant competitors or alternatives, differentiators, strengths, and tradeoffs. |
| **Messaging Framework** | Positioning, core narrative, elevator pitch, and messaging pillars. |
| **Proof Points** | Quantitative, customer, third-party, or industry evidence that can support brand claims. |
| **Value Propositions** | Audience-specific value propositions, benefits, supporting evidence, and competitive advantages. |

AI can use this information to create more consistent, differentiated, and audience-relevant messaging.

## Product

The **Product** folder describes what the brand sells or provides and how its offerings relate to customer needs.

| File | What it covers |
| --- | --- |
| **Capabilities Matrix** | Important capabilities, categories, or offer areas and how they map to audiences or use cases. |
| **Integrations & Ecosystem** | Relevant integrations, partners, platforms, or other ecosystem relationships. |
| **Product Portfolio** | The brand's products, services, solutions, or offer categories, including their audiences and differentiators. |

AI can use this information to describe offerings accurately and connect them with relevant customer needs and use cases.

## Content Guidelines

The **Content Guidelines** folder describes how the brand should communicate.

| File | What it covers |
| --- | --- |
| **Channel Guide** | How content, tone, formats, and practices can vary by channel. |
| **Content Standards** | Expectations for content quality, structure, review, governance, and maintenance. |
| **Style Guide** | Writing style, terminology, formatting, punctuation, capitalization, and other editorial conventions. |

AI can use this information to generate content that is more consistent with the brand across channels and content types.

## Customer Evidence

The **Customer Evidence** folder organizes information that can support brand claims and demonstrate credibility.

| File | What it covers |
| --- | --- |
| **Case Studies** | Examples that demonstrate the brand's value, outcomes, or proposition. |
| **Evidence Framework** | Types of available evidence, where they are useful, and how they can support different audiences or journey stages. |
| **Success Metrics** | Quantitative evidence, outcomes, benchmarks, and other relevant measures of success. |
| **Testimonials** | Attributable customer or third-party statements and their approved usage where available. |

AI can use this information to support generated content with relevant evidence instead of relying only on promotional claims.

## How generated information can vary

Every brand context uses the same standard folders and files. The information generated within them varies based on the source you provide and the publicly available information SitecoreAI can find about the brand.

Generated content can include information found directly in those sources as well as interpretations based on the available information. Some files might contain limited information when relevant details are not publicly available.

Review the generated files and update incomplete or inferred information with approved brand guidance where needed. See [View and edit brand context files](view-and-edit-brand-context-files.md) and [Manage brand context folders and files](manage-brand-context-folders-and-files.md) for details.
