# Delete brand context

Admins and owners can delete brand context when it is outdated, duplicated, no longer needed, or when its analysis failed during creation. Deletion is permanent and cannot be undone.

> [!note]
>
> To delete brand context, you must have an **Organization Admin** or **Organization Owner** role in Sitecore Cloud Portal.

To delete a brand context:

1. In the top-right corner of the page, click **Brand Context** :mdiBookOpenPageVariantOutline:.
2. On the **Brand context** page, find the brand context you want to delete.
3. Next to the brand context, click the horizontal ellipsis icon :mdiDotsHorizontal:, then select **Delete**.
4. In the **Delete brand context** dialog, click **Delete**.
