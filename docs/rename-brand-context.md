# Rename brand context

Admins and owners can rename a brand context when its current name is outdated, unclear, or no longer accurately describes its contents.

To rename a brand context:

1. In the top-right corner of the page, click **Brand Context** :mdiBookOpenPageVariantOutline:.
2. On the **Brand context** page, find the brand context you want to rename.
3. Next to the brand context, click the horizontal ellipsis icon :mdiDotsHorizontal:, then select **Rename**.
4. In the **Rename brand context** dialog, enter a new brand context name and then click **Save**.
