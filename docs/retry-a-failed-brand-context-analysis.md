# Retry a failed brand context analysis

If SitecoreAI cannot complete the analysis for a brand context, the status is shown as **Failed**. You can retry the analysis to generate the brand context folders and files again.

> [!note]
>
> To retry a failed brand context analysis, you must have an **Organization Admin** or **Organization Owner** role in Sitecore Cloud Portal.

To retry a failed brand context analysis:

1. In the top-right corner of the page, click **Brand Context** :mdiBookOpenPageVariantOutline:.
2. On the **Brand context** page, find the brand context with the **Failed** status.
3. Next to the brand context, click the horizontal ellipsis icon :mdiDotsHorizontal:, then select **Retry**.

SitecoreAI starts analyzing the selected source again. The status changes to **In progress** while the analysis runs.
