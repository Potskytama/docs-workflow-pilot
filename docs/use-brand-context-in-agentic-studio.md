# Apply brand context in Agentic studio

In Agentic studio, you can select a [brand context](brand-context.md) for a free-form chat or an agent-driven task. The chat or agent can then use relevant information from across the brand context to ground its response.

You do not need to select individual brand context files or folders.

To apply brand context:

1. In SitecoreAI, open the Agentic studio [chat interface](https://doc.sitecore.com/sai/en/users/sitecoreai/working-with-agentic-studio/understanding-chat.html#accessing-the-chat-interface).
2. Start a new chat.
3. Optionally, select the [agent](https://doc.sitecore.com/sai/en/users/sitecoreai/working-with-agentic-studio/understanding-agents/run-an-agent.html) that you want to run. For example, select **Brief Generator**.
![Select the the agent to to use.](images/optional-select-agent-in-chat.png)
4. Click **Context** :mdiBookOpenBlankVariantOutline:.
5. On the **Brand Context** tab, select the brand context that you want to use.
![Click Context and select the brand context that you want the chat to to use.](images/select-brand-context-agentic.png)
6. Enter a prompt describing the result you want. For example:
    - *Create a comprehensive campaign brief aligning target personas (Audiences), the central value proposition (Messaging), specific feature details (Product), social proof points (Customer Evidence), and execution rules (Content Guidelines)*.
7. When using an agent, configure any required parameters, such as target languages or content channels.
8. Optionally, provide additional information, such as related items or uploaded files.
9. Press **Cmd + Enter** on macOS or **Ctrl + Enter** on Windows to submit the prompt.

The chat or agent uses relevant information from the selected brand context when generating its response. Review the result and refine your prompt, parameters, or supporting information as needed.
